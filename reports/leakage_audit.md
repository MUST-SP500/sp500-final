## 实验方式与边界

控制实验使用 `src/leakage_audit.py` 中独立的逻辑回归（C=1、max_iter=2000、seed=42），每折独立 fit 中位数填补、1%/99% 截尾、标准化，再拟合分类器。使用与正式建模共同的 splits.json；未按测试 AUC 选择参数或更换随机种子。

随机标签在完整可用样本中一次性打乱，保留类别数量，再按原切分训练/评估；未来信息实验在正常 22 列之外故意加入 next_ret。未来注入组得到高 AUC 是预期的作弊表现，不能作为项目的预测成绩。它说明本审计实验能对明显的未来信号产生异常高分，不意味着已实现可自动阻止所有泄漏的检测器。

逐折 AUC 可能因每年只有约 52 个样本明显波动；这里的判据应用于合并样本外 AUC。随机对照通过不是没有任何泄漏的数学证明。截断不变性仅针对给定的清洗面板，未验证数据供应商历史修订的 point-in-time 性质。

预注册还要求“时间平移应导致策略失效”。当前只运行了 52 周滞后特征的分类诊断；尚未与 B4/B6 正式模型及回测连接，不能据此勾选该要求。PCA/Autoencoder 的训练内拟合也需由 P5 在实际集成中另行验证。

B1 的 ^GSPC 下载此前失败，其交叉校验尚需补齐。B6 完整回测对账仍未实现。以上通过项不代表整个项目已通过最终审计。

## 复现

在仓库根目录依次运行：

```powershell
uv run python -m src.features
uv run python -m src.labels
uv run python -m src.splits
uv run python -m src.leakage_audit
uv run pytest
```

控制实验结果在 `data/processed/control_summary.csv`、`control_folds.csv` 和 `control_predictions.csv`。这些均为本地生成数据，不提交 git。现有 pipeline.py 的 B3 调度仍为骨架；本阶段使用上述独立入口，集成由 P6 对齐。
