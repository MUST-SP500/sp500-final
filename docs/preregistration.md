## 1. 主结论的唯一口径

| 项目 | 取值 |
|---|---|
| 主模型 | L2 逻辑回归（标准化后 22 特征） |
| 主决策规则 | R1 固定阈值 0.5 |
| 主指标 | **5 bps 成本下的净 Sharpe**（2008–2025，周频，年化） |
| 主对照组 | 买入持有 SPY（同口径、同成本） |
| 次指标 | CAGR、MaxDD（周频+日频）、年换手、平均仓位、Brier、AUC |
| 成功判据 | 效应量 + 95% 置信区间，**不以 p 值二分** |

## 2. 数据与口径

| 项目 | 取值 |
|---|---|
| 区间 | 1996-01-01 – 2025-12-31 |
| 主标的 | SPY 总收益合成价（`adj_close/close` 派生复权 OHLC） |
| 交叉校验 | ^GSPC，与 SPY 日收益相关性须 > 0.99 |
| 宏观滞后 | DGS10 / DTB3 滞后 1 个交易日 |
| VIX | **统一 `shift(1)`**（收盘晚 15 分钟） |
| 频率 | 周频，周 = ISO 周最后一个交易日 |
| 价格水平 | **禁止**把价格绝对水平用作特征 |

## 3. 标签与执行时点

```text
决策   t   = 第 w 周最后交易日收盘
执行   t+1 = 第 w+1 周第一个交易日开盘
平仓   t+2 = 第 w+2 周第一个交易日开盘
标签   r_oo = ln(O_adj[t+2] / O_adj[t+1])      # 对数，仅用于建模与画图
分类   y = 1 if r_oo > 0 else 0
回测   R = O_adj[t+2] / O_adj[t+1] - 1         # 简单收益，不可与对数混算
```

## 6. 事前声明的局限（写进报告，不得删）

1. 超参数在全样本外区间固定，未逐折重选；结论代表"一次冻结的建模决策"。
2. 验证集只有 2006–2007，恰好是金融危机前夜，存在"验证期 regime 特殊"的风险。
3. 样本外约 18 年，**不足以检测 Sharpe 差 < 0.4–0.6 的改善**；小于功效下限的差异一律表述为"无法区分"。
4. 单资产、周频、long/cash，不覆盖横截面与日内信息。
