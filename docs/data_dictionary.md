## 口径说明（写进报告"数据"一节）

1. **复权价是"总收益合成价格"，不是可成交价。** 收益等价于分红再投资，但历史价格水平不可成交。
2. **成本按名义比例（bps）计**，因此复权与否不影响成本口径。
3. 复权因子对同一窗口内所有价格是**同一常数**，所以比率型特征（价格/均线、收益率、波动）不受未来分红影响——**这是禁止用价格绝对水平做特征的原因**。
4. **周的定义**：该 ISO 周的最后一个交易日。禁止 `resample('W-FRI')`，假期周会错位。
5. **VIX 滞后 1 日**：CBOE 收盘 16:15 ET，比股票收盘晚 15 分钟，不滞后即有 15 分钟隐性前视。
6. **宏观发布滞后**：H.15 约 16:15 ET 发布，晚于股票收盘，至少滞后 1 个交易日。

## 数据质量检查项（`src/validate.py` 已实现）

- [ ] 日期唯一、升序
- [ ] OHLC 关系：`low <= min(open, close)`，`high >= max(open, close)`
- [ ] 复权价格连续性、拆股/分红事件合理
- [ ] 交易日数量与 NYSE 日历大致一致
- [ ] 缺失率（宏观前向填充后 < 0.5%）
- [ ] 极端收益（|r| > 20%）是真实危机还是数据错误
- [ ] SPY 与 ^GSPC 日收益相关性 > 0.99
