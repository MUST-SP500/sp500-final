> 本版不做美元指数（DXY）：它对周频择时的增量不明确，一周工期里不值得多一个数据源。

## `daily_panel.parquet`（中间产物，给 B3 特征工程用）

日频、已复权、已对齐宏观，列：`date, f, open, high, low, close, adj_close, volume, vix, dgs10, dtb3`（11 列）。周面板由它聚合而来，两者同源，不要各算一套。

## 口径说明（写进报告"数据"一节）

1. **复权价是"总收益合成价格"，不是可成交价。** 收益等价于分红再投资，但历史价格水平不可成交。
2. **成本按名义比例（bps）计**，因此复权与否不影响成本口径。
3. 复权因子对同一窗口内所有价格是**同一常数**，所以比率型特征（价格/均线、收益率、波动）不受未来分红影响——**这是禁止用价格绝对水平做特征的原因**。
4. **周的定义**：该 ISO 周的最后一个交易日。禁止 `resample('W-FRI')`，假期周会错位。
5. **VIX 滞后 1 日**：CBOE 收盘 16:15 ET，比股票收盘晚 15 分钟，不滞后即有 15 分钟隐性前视。
6. **宏观发布滞后**：H.15 约 16:15 ET 发布，晚于股票收盘，至少滞后 1 个交易日。

## 原始数据快照与可复现性（`data/raw/`）

- `data/raw/yahoo/{SPY,GSPC,VIX}.csv`、`data/raw/fred/{DTB3,DGS10}.csv` 是**下载当日的快照**：只读、不进 git（`.gitignore` 已排除）。文件名去掉 `^`（Windows 安全），`VIX.csv` 即 `^VIX`。
- `data/raw/manifest.json` 逐个文件记 `url / retrieved_at / rows / date_range / sha256`，是"这份数据是哪天下的"的唯一凭据。
- **`sha256` 是快照指纹，不是跨机一致性承诺**：雅虎的 `adj_close` 每次请求会被服务端重算复权因子，实测同一区间两次下载差异在 1e-4 量级，而 `open/high/low/close/volume` 逐字节相同。所以跨机核对口径是**行数 + 日期区间 + `close` 一致**，`adj_close` 允许 1e-4 漂移；报告里引用数据必须写明 `retrieved_at`。
- 缓存规则：文件已覆盖请求区间（两端各留 7 天缓冲，应对元旦/周末等非交易日）即跳过下载；`SP500_REFRESH=1` 或 `download_all(..., refresh=True)` 强制重下。
- FRED 序列的交易日比交易所少（H.15 假期不出数）：1996–2025 区间价格类 7,550 行，宏观类 7,505 行，属正常。

## 数据质量检查项（`src/validate.py` 已实现）
- [ ] 日期唯一、升序
- [ ] OHLC 关系：`low <= min(open, close)`，`high >= max(open, close)`
- [ ] 复权价格连续性、拆股/分红事件合理
- [ ] 交易日数量与 NYSE 日历大致一致
- [ ] 缺失率（宏观前向填充后 < 0.5%）
- [ ] 极端收益（|r| > 20%）是真实危机还是数据错误
- [ ] SPY 与 ^GSPC 日收益相关性 > 0.99
- [ ] SPY 复权序列与 ^SP500TR 逐年偏差 < 0.3%（总收益口径的独立对账）

## 已实测结论（2026-11-23，1996-01-05 ~ 2025-12-31）

| 检查 | 实测 | 判定 |
|---|---|---|
| 面板规模 | 1,566 周 × 12 列；日面板 7,550 × 11 | ✅ |
| 每年周数 | 52–53，无断年 | ✅ |
| 任意缺失 | 12 列全部 0 缺失 | ✅ |
| 周 `close` vs 当日 `adj_close` | 逐行完全相等（`atol=0`） | ✅ |
| `vix` 是否等于前一交易日 VIX | 1,566 行全对上 | ✅ |
| OHLC 关系 | 全部满足 | ✅ |
| **SPY vs ^GSPC 相关** | 全样本 **0.9853**；2010 年起 **0.9986** | ⚠️ 见下 |

**关于 0.9853**：不是对齐错误。lag 检验显示 lag=0 相关系数 0.985，lag=±1 天都是 −0.08，日期对齐正确；分区间看 1996–2000 的日收益中位绝对差 18.7bp、2010 年起降到 2.7bp。原因是 2001 年前 SPY 最小变动价位 1/16 美元（约 9bp），加上 ^GSPC 收盘四舍五入，两序列在早期本身就带这个量级的噪声。**结论：口径正确，>0.99 的验收线只在 2010 年后成立**；建议把这行改成「2010 年起 > 0.99，全样本以中位绝对差 < 20bp 为准」。^GSPC 只用于校验、不进模型，不影响建模。
