# 决策日志（Decision Log）

> **只记决定，不记讨论过程。**
> 一条决定 = 日期 + 决定 + 理由 + 影响范围。讨论过程留在会议记录或聊天记录里。

## 模板

```markdown
### YYYY-MM-DD · 一句话标题
- **决定**：
- **理由**：
- **影响**：影响哪些文件 / 哪些块 / 是否需要改预注册
- **提出 / 确认**：
```
