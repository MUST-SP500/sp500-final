没做这一步就写"未做"，不要编。

## 记录模板

| 项目 | 内容 |
|---|---|
| 日期 | ____-__-__ |
| 机器 / 系统 | 例：Windows 11 / 16G 内存 / 无独显 |
| 是否全新克隆 | 是 / 否（从干净 clone 算数） |
| 执行命令 | `uv sync` → `uv run main.py --check` → `uv run main.py` |
| 各步耗时 | 下载 __ s / 清洗 __ s / 特征 __ s / 模型 __ s / 回测 __ s |
| 过程中出的错 | 有就写：报什么、怎么解决的 |
| 最终结果 | `data/processed/weekly_panel.parquet` 共 ____ 行，日期 ____ ～ ____ |
| 与开发机是否一致 | 行数一致？指标一致？（不一致就说明有环境或随机性问题） |

## 常见问题

- `uv: command not found`：装完要**关掉终端重开**。
- 下载失败：先确认能连外网；再检查 `data/raw/` 里有没有上次的缓存，有就说明脚本没读缓存。
- 结果和开发机不同：先查随机种子是不是都从 `config.yaml` 取，再查 pandas 版本（`uv.lock` 里锁死的版本才作数）。
