━━━━━━━━━━━━━━━━━━━━
一、装 uv（只做一次）
━━━━━━━━━━━━━━━━━━━━
Windows 用 PowerShell（不是 CMD）：
  powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

macOS / Linux：
  curl -LsSf https://astral.sh/uv/install.sh | sh

装完关掉终端重开，输入 uv --version 有版本号就行。

注意：不要用 pip install，也不要自己 python -m venv。依赖唯一真源是 pyproject.toml + uv.lock，混用会导致别人复现不了。

  cd sp500-final

之前拉过的：
  git switch main
  git pull

必须是最新 main。旧版只有原始数据，没有清洗好的面板。

五、数据在哪、字段什么意思
━━━━━━━━━━━━━━━━━━━━
  data/processed/weekly_panel.parquet   建模主表，一行=一周（1566 行 × 12 列）

两个常用命令：

━━━━━━━━━━━━━━━━━━━━
六、两条必须遵守的口径
━━━━━━━━━━━━━━━━━━━━
1. 特征在 daily_panel 上算（20/60 日均线、20 日波动率、RSI 等），再按 ISO 周取该周最后一个交易日，与 weekly_panel.date 对齐。周频只有 1566 行，直接算 20 周均线会吃掉前两年样本。
2. 不许自己复权、不许自己 resample('W-FRI')。口径唯一真源是 src/data_clean.py，要改先改 docs/variable_descriptions.md 和测试，再改代码。

另外：weekly_panel 里没有 label_ret / label_up / next_ret 三列，这三个由 B3 的 src/labels.py 追加。

八、常见问题
━━━━━━━━━━━━━━━━━━━━
Q1 download 报 403 / 超时 / 连不上
   雅虎和 FRED 在国内网络经常连不上，先开 VPN（TUN 模式最稳）再跑。实在不行找熊泽睿要三个文件：weekly_panel.parquet、daily_panel.parquet、manifest.json，放到对应路径就能用，不用跑 download。

Q2 git push 报 fatal: could not read Username
   Windows 凭据管理器里的 GitHub 登录失效。关掉终端重开，git push 会弹浏览器，登录一次就好。

Q3 uv sync 报 lock 文件不一致
   先 git pull 拿最新版本；还不行 git checkout -- uv.lock。不要手动编辑 uv.lock。

Q4 pytest 不是 100 passed
   先 git pull 确认在最新 main 上；还不行删掉 .venv 目录重新 uv sync。

Q5 数据行数不是 1566
   九成是代码版本旧了（git log -1 看 commit）。数据区间固定 1996-2025，行数不该变。
